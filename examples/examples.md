# Code Examples {#examples_index}

Collection of implementation examples for TrEESaP.

- @subpage example-01-wave-equation: Introduces basic concepts&mdash;right-hand side functors, stencil implementations, the tensor aliasing system, and time-integration&mdash;by implementing the scalar wave equation.

- @subpage example-02-temporaries: Explains tensor temporaries (`treesap::tensor::TensorAliasBase::Temporary`) and showcases their intended usage in a concrete RHS implementation.
